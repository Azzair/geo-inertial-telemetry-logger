# Інструкція з розгортання та встановлення мобільного застосунку
**Geo-Inertial Telemetry Suite** (PWA & Нативний мобільний застосунок)

Цей посібник містить повні відповіді на ваші запитання та детальну покрокову інструкцію щодо запуску застосунку на смартфонах у вигляді PWA (Progressive Web App) або повноцінного нативного мобільного застосунку (Android APK / iOS IPA).

---

## 1. Відповіді на ключові запитання

### Чи може запустити PWA будь-хто?
**Так, будь-хто!** 
У цьому полягає головна перевага Progressive Web App. Застосунок не потребує публікації в Google Play Store чи Apple App Store, де потрібні платні акаунти розробника та тривала перевірка модераторами.
* **Як користувач отримує застосунок:** Ви просто скидаєте посилання на сайт користувачу. Він відкриває його в браузері свого смартфона і за пару кліків встановлює як окрему іконку на головний екран.
* **Пристрій:** Працює на Android (через Google Chrome, Edge, Firefox, Brave) та на iOS/iPhone (через Apple Safari).

### Чи потрібне підключення до мережі інтернет?
**Ні, інтернет не потрібен!** (Окрім першого відвідування сайту для встановлення).
Завдяки розробленому Сервісному Воркеру (`sw.js`) та технології Offline Cache:
1. **Автономність інтерфейсу:** HTML-код, стилі Tailwind, графічні іконки, математичні та фізичні алгоритми, а також JS-скрипти зберігаються безпосередньо у локальній пам’яті (Cache Storage) смартфона. При запуску застосунок завантажується миттєво з пристрою, навіть якщо телефон у режимі "У літаку" або в горах без зв’язку.
2. **Автономність датчиків:** Фізичні апаратні компоненти вашого смартфона — **GPS супутники (ГНСС)** та **інерціальні датчики руху IMU (акселерометр та гіроскоп)** — є вбудованим залізом. Браузерні інтерфейси W3C Geolocation API та Device Motion API отримують дані безпосередньо від мікросхем плати телефону, не надсилаючи жодних запитів до серверів.
3. **Локальне збереження:** Усі сесії та записані логи зберігаються у локальній базі браузера (`localStorage`). Ви можете записувати десятки заїздів, зупиняти, створювати CSV файли, видаляти або накопичувати дані повністю офлайн. Коли ви натискаєте "Зупинити запис" — згенерований CSV-файл автоматично скачується прямо в локальну папку завантажень телефону (`Downloads`), без завантажень на сервер.
4. **Погода:** Запит поточної температури повітря (з API-сервера) зазвичай потребує мережі. Якщо інтернет відсутній, застосунок не зламається: сервісний воркер перехопить запит та видасть коректні резервні дані. Ви також можете вручну налаштувати температуру повзунком на першому екрані.

## 2. Варіант А: Встановлення як PWA (Найпростіший спосіб)

Завдяки доданим до проекту файлам сервіс-воркера (`/public/sw.js`), іконкам (`/public/icon.svg`, `/public/icon-512.png`) та файлу маніфесту (`/public/manifest.json`), ваш веб-сайт автоматично розпізнається смартфонами як мобільний застосунок.

### Для користувачів Android (Google Chrome):
1. Відкрийте посилання на ваш додаток у браузері **Google Chrome** на телефоні.
2. Зверху чи знизу з'явиться спливаючий рядок: "Додати Geo-Inertial Telemetry на головний екран" (або натисніть кнопку з символом встановлення в адресному рядку).
3. Якщо повідомлення немає, натисніть на **три крапки** у правому верхньому кутку Chrome та виберіть **"Встановити застосунок"** (або "Add to Home screen").
4. Застосунок з'явиться на робочому столі з фірмовою темно-зеленою супутниковою іконкою та буде запускатися на весь екран без рамки браузера.

### Для користувачів iOS / iPhone (Apple Safari):
1. Відкрийте посилання на додаток виключно в стандартному браузері **Safari**.
2. Натисніть кнопку **"Поділитися"** (іконка квадрата зі стрілкою вгору в нижньому меню браузера).
3. Прокрутіть список параметрів вниз і виберіть пункт **"Додати на початковий екран"** (Add to Home Screen).
4. Натисніть кнопку "Додати" у верхньому правому кутку. Застосунок з'явиться серед інших додатків iPhone і буде запускатися як окремий повноекранний софт.

## 3. Варіант Б: Створення Нативного Застосунку (.APK для Android)

Якщо вам потрібен класичний двійковий файл **Android App Bundle (.aab)** для публікації в Play Store або інсталяційний **Android Package (.apk)** для прямого копіювання на телефон, найкраще скористатися фреймворком **Capacitor** від Ionic. 

Ми вже додали pre-configured файл конфігурації `capacitor.config.json` до кореня вашого проекту!

### Покрокова інструкція збірки APK:

#### Крок 1. Підготовка оточення на вашому ПК
Переконайтеся, що на вашому комп'ютері встановлено:
1. **Node.js** (версії 18 або новіше).
2. **Android Studio** (офіційна IDE для побудови Android додатків, завантажте безкоштовно).
3. Переконайтеся, що в Android Studio встановлено **Android SDK** та **Command-line tools** через SDK Manager.

#### Крок 2. Компіляція веб-проєкту
Спочатку зберіть оптимізовані статичні файли React:
```bash
npm run build
```
Ця команда створить готову до офлайн-роботи папку `dist/` з усіма необхідними CSS, JS та HTML скриптами.

#### Крок 3. Встановлення інструментів Capacitor
Встановіть головні залежності Capacitor у ваш проект:
```bash
# Встановлення CLI та Core
npm install @capacitor/core @capacitor/cli

# Встановлення Android-платформи
npm install @capacitor/android
```

#### Крок 4. Ініціалізація та додавання Android-платформи
Ініціалізуйте Capacitor (ми вже прописали налаштування в `capacitor.config.json`, але про всяк випадок перевіримо):
```bash
# Якщо конфіг уже є, одразу додаємо структури Android Studio:
npx cap add android
```
Ця команда згенерує повноцінну директорію мобільного софту під назвою `android/` у вашому проекті.

#### Крок 5. Синхронізація зібраного коду
Кожного разу, коли ви оновлюєте інтерфейс у React та запускаєте `npm run build`, вам потрібно переносити оновлені файли до мобільної папки Android Studio. Робиться це однією простою командою:
```bash
npx cap sync
```

#### Крок 6. Відкриття та збірка в Android Studio
Запустіть рідне середовище розробки з мобільним кодом за допомогою клієнт-команди:
```bash
npx cap open android
```
1. Android Studio автоматично завантажить ваш проєкт, запустить збірку Gradle та завантажить залежності.
2. Для отримання інсталяційного файлу: перейдіть у верхньому меню Android Studio в:
   **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)**
3. Після завершення компіляції Gradle, у правому нижньому кутку з’явиться спливаюче сповіщення "Build APKs: APK(s) generated successfully". Натисніть кнопку **"Locate"** у сповіщенні, щоб відкрити папку з готовим інсталяційним файлом **`app-debug.apk`**.
4. Скиньте цей файл на ваш Android-смартфон через USB-кабель, Telegram або Google Drive та встановіть його directly!





Як зібрати цей проект, щоб запустити на телефоні як застосунок?
Оскільки це React + Vite застосунок, який працює за допомогою стандартних веб-інтерфейсів (Geolocation API для супутників, DeviceMotion API для датчиків прискорення/гіроскопа та WakeLock API для запобігання згасанню екрану), у вас є два чудових рішення.
Варіант А: Progressive Web App (PWA) — Нашвидший і найзручніший спосіб
PWA дозволяє користувачеві «встановити» звичайний сайт на робочий стіл смартфона як програму з власною іконкою, що працює на весь екран (без рамок браузера) та підтримує запуск офлайн.
Встановіть плагін PWA для збирача:
code
Bash
npm install vite-plugin-pwa --save-dev
Додайте конфігурацію в vite.config.ts:
code
TypeScript
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { VitePWA } from 'vite-plugin-pwa';

export default defineConfig({
  plugins: [
    react(),
    VitePWA({
      registerType: 'autoUpdate',
      manifest: {
        name: 'Geo-Inertial Telemetry',
        short_name: 'Telemetry',
        theme_color: '#020617', // Темний фон slate-950
        icons: [
          { src: 'pwa-192x192.png', sizes: '192x192', type: 'image/png' },
          { src: 'pwa-512x512.png', sizes: '512x512', type: 'image/png' }
        ]
      }
    })
  ]
});
Зберіть та опублікуйте:
Виконайте команду npm run build та вивантажте папку dist/ на будь-який безкоштовний статичний хостинг з підтримкою HTTPS (наприклад, GitHub Pages, Vercel, Netlify або Firebase Hosting).
Встановлення на телефон:
На Android (Chrome): Перейдіть за посиланням сайту, натисніть три крапки праворуч вгорі та оберіть «Додати на головний екран» (або встановити застосунок).
На iOS (Safari): Перейдіть на сайт, натисніть кнопку Поділитися (стрілка вгору) та виберіть «Додати до початкового екрана».
Варіант Б: Capacitor (Ionic) — Справжній нативний застосунок (.APK / iOS App)
Якщо вам потрібен повністю скомпільований файл програми (на кшталт .apk), скористайтеся бібліотекою Capacitor від Ionic. Вона упаковує ваш React код у повноцінне нативне середовище.
Ініціалізуйте Capacitor у вашому проекті:
code
Bash
npm install @capacitor/core @capacitor/cli
npx cap init "Geo Inertial Telemetry" "com.telemetry.geoinertial" --web-dir=dist
Додайте платформи (Android або iOS):
code
Bash
npm install @capacitor/android @capacitor/ios
npx cap add android
npx cap add ios
Налаштування нативних дозволів:
Оскільки логер використовує GPS та датчики руху, вам обов'язково треба дозволити їх використання у конфігураціях систем:
Для Android (android/app/src/main/AndroidManifest.xml):
Переконайтеся, що всередині тегу <manifest> є такі дозволи:
code
Xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.WAKE_LOCK" />
Для iOS (ios/App/App/Info.plist):
Додайте ключі для запиту дозволу у користувача:
code
Xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Нам потрібен доступ до вашого GPS для вимірювання швидкості та відстані.</string>
<key>NSMotionUsageDescription</key>
<string>Нам потрібен доступ до акселерометра та гіроскопа для вимірювання інерції руху.</string>
Компіляція програми:
Кожного разу, коли ви змінюєте код у React, виконуйте наступну просту послідовність команд:
code
Bash
# 1. Збираємо файли React у веб-пакет
npm run build

# 2. Перекидаємо ці файли у нативні папки Android/iOS
npx cap sync

# 3. Відкриваємо проект у Android Studio або Xcode для білду файлу .APK чи встановлення
npx cap open android
npx cap open ios
В Android Studio після відкриття ви зможете натиснути кнопку Build -> Build Bundle(s) / APK(s) -> Build APK або підключити ваш телефон по USB-кабелю з режимом налагодження (USB Debugging) та запустити програму напряму на пристрій за 1 клік!
